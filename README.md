# 📚 Aplicação de TAD Lista em C

Este repositório contém a implementação de uma atividade prática da disciplina de Estrutura de Dados, desenvolvida utilizando ANSI C, com foco na aplicação do Tipo Abstrato de Dados (TAD) Lista.

O projeto realiza leitura de arquivos, armazenamento de dados em listas e consultas entre projetos e membros utilizando relações entre estruturas.

## 🚀 Funcionalidades Desenvolvidas

O sistema permite:

* Leitura de arquivos `.txt`
* Carregamento de dados em listas
* Associação entre membros e projetos
* Busca de:

  * projetos de um membro
  * membros de um projeto
* Exibição interativa através de menu no terminal

## 🧠 Conceitos Trabalhados

Durante o desenvolvimento foram utilizados conceitos importantes da disciplina, como:

* TAD Lista
* Structs em C
* Manipulação de arquivos
* Arrays
* Relacionamento entre dados
* Busca e filtragem em listas
* Modularização de código

## 📂 Estrutura dos Dados

Os dados são organizados através de três estruturas principais:

* Projetos
* Membros
* Relações entre projetos e membros

Essas informações são carregadas a partir de arquivos `.txt` fornecidos para a atividade.

## 💻 Tecnologias Utilizadas

* ANSI C
* Manipulação de arquivos (`fopen`, `fclose`, `fscanf`, `fgets`)
* Estruturas de Dados

## 🎯 Objetivo

O objetivo deste trabalho é praticar manipulação de listas e arquivos em linguagem C, reforçando conceitos fundamentais de Estrutura de Dados e organização de informações.
